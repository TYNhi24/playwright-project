# Practice samples

Ví dụ requirement, Jira issue, manual/API test case. Nội dung nghiệp vụ mẫu được giữ nguyên. URL/tài khoản trong nguồn phải xác minh trước khi dùng; không tái sử dụng credentials hoặc truy cập dịch vụ nếu chưa có quyền.

- `requirements/crm/`: requirement CRM theo module.
- `requirements/ecommerce/`: requirement ecommerce.
- `requirements/jira/`: requirement Jira và ảnh đính kèm.
- `testcases/crm/`: manual test case CRM.
- `testcases/api/`: case API user/book management.

Artifact độc lập framework. Khi automation, map sang Playwright Test theo evidence UI/API và giữ traceability.
